**** Create a new repository on the command line:

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/SikderMdSharifulIslam/test.git
git push -u origin main

**** Push an existing repository from the command line:
git remote add origin https://github.com/SikderMdSharifulIslam/test.git
git branch -M main
git push -u origin main  


note: 
1. username & email deyar por (git config --global --list) ei command diye check kora jabe j thik moto nise kina.
2. (git remote -v) ei command diye check korte parbo amra kon repository te achi akn
